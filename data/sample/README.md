# Sample Data for ImageToChaste

This directory contains lightweight sample microscopy images intended for quickstart validation, automated testing, and demonstration:

1. **`drosophila_germband_f009.png`** (81 KB):
   - Authentic brightfield microscopy scan (Frame 9, 310 ground-truth epithelial cells) from **Blankenship et al. (2006)** studying *Drosophila melanogaster* embryonic germband extension during tissue morphogenesis.
   - Reference: *Blankenship, J. T., Backovic, S. T., Sanny, J. S. P., Weitz, O., & Zallen, J. A. (2006). Multicellular rosette formation links planar cell polarity to tissue morphogenesis. Developmental Cell, 11(4), 459–470.*

2. **`sample_cells.png`** (549 KB):
   - A 512×512 synthetic fluorescence scan simulating confluent cell colonies with membranes, nuclei, and uneven background illumination. Used in CI unit tests.
